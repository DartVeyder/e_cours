# Журнал змін (Changelog)

Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/).

## [1.4.1] - 2026-09-10

### ✨ Додано (Added)
- **Автоматичний вибір спеціальності**:
  - Якщо у студента зареєстровано лише 1 картку спеціальності, система обирає та активує її автоматично при переході на сторінку вибору дисциплін або головний екран.
  - Якщо у студента кілька спеціальностей (паралельне навчання) і жодна ще не обрана, виводиться помітний блок попередження зі швидкими кнопками перемикання спеціальності як на головній панелі, так і на екрані вибору дисциплін.
- **Відображення каталогу вибіркових дисциплін без обраної спеціальності**:
  - Список доступних курсів завжди відкритий для ознайомлення, а в колонці семестру відображається інформаційний бейдж «Оберіть спеціальність».
- **Покрокова інструкція та розширений FAQ**:
  - Оновлено покроковий гайд та додано відповіді на часті питання (FAQ) щодо автоматичного вибору, роботи з двома спеціальностями одночасно, зміни або скасування вибору.
  - Додано підказки в інструкцію та блок регламенту адміністратора.
- **Комплексні Feature-тести**:
  - Додано набір автотестів `SpecialtyAutoSelectionAndWarningTest` для перевірки автовибору, попереджень, мультіспеціальностей та перемикання (загалом 49 автотестів у системі).

### 🐛 Виправлено (Fixed)
- **Виправлено відправку форм у Orchid Platform**: усунено вкладені теги `<form>` у blade-шаблонах через використання HTML5-атрибутів `form="post-form"` та `formaction`, що вирішило проблему зависання кнопок у стані завантаження (`.btn-loading`).
- **Виправлено висоту блоків Layout::view**: перевизначено стиль `.h-100` для компактного відображення попереджувальних блоків без розтягування екрана.

## [1.4.0] - 2026-09-08

### ✨ Додано (Added)
- **Версійність системи (Versioning)**:
  - Додано параметр версії `APP_VERSION=1.4.0` у конфігурацію [config/app.php](file:///e:/OSPanel/home/e-cours.loc/config/app.php) та [.env.example](file:///e:/OSPanel/home/e-cours.loc/.env.example).
  - Створено глобальний футер [footer.blade.php](file:///e:/OSPanel/home/e-cours.loc/resources/views/vendor/platform/footer.blade.php) із зазначенням авторських прав університету та бейджем версії `v1.4.0`.
  - Додано бейдж версії на головний екран [main.blade.php](file:///e:/OSPanel/home/e-cours.loc/resources/views/main.blade.php) та в опис екрана «Налаштування системи» [SettingsScreen.php](file:///e:/OSPanel/home/e-cours.loc/app/Orchid/Screens/Setting/SettingsScreen.php).
- **Окрема сторінка налаштувань Google Таблиць**: створено зручний ергономічний екран `GoogleSheetsSettingsScreen` (`/settings/google-sheets`) у блоковому форматі без зайвих вкладок. Налаштування згруповані за сутностями (Режим роботи, Таблиця «Студенти», Таблиця «Дисципліни»).
- **Вибір назви аркуша (вкладки)**: додано можливість вказувати окремі назви аркушів як для робочого, так і для тестового режимів (наприклад, тестовий аркуш `Студенти_тест` або `Тест` всередині тієї самої таблиці).
- **Розділення Робочих та Тестових Google Таблиць**: налаштування та перемикання між робочими і тестовими таблицями/аркушами здійснюється безпосередньо в базі даних (Single Source of Truth), без потреби редагувати `.env` файл на сервері.
- **Швидке копіювання даних (ПІБ, Група, ЄДЕБО, Email)**: на сторінці студентів ([StudentListLayout](file:///e:/OSPanel/home/e-cours.loc/app/Orchid/Layouts/Student/StudentListLayout.php)) додано сучасні кнопки копіювання в 1 клік, які плавно з'являються при наведенні курсора на клітинку з візуальною анімацією підтвердження.
- **Розділення головного екрана за ролями користувачів ([MainScreen](file:///e:/OSPanel/home/e-cours.loc/app/Orchid/Screens/MainScreen.php) / [main.blade.php](file:///e:/OSPanel/home/e-cours.loc/resources/views/main.blade.php))**:
  - **Для студента**: особистий кабінет з інформацією про навчання (група, спеціальність, факультет, форма навчання, ЄДЕБО), живий статус вибору дисциплін (відкрито/закрито), інтерактивний прогрес-бар обраних дисциплін з лімітами, список обраних курсів по семестрах, покрокова інструкція вибору, інтерактивний блок поширених запитань (FAQ) та пряма кнопка переходу до вибору.
  - **Для адміністратора та деканату**: панель аналітики та керування (KPI лічильники: студенти, активні дисципліни, академічні групи, здійснені вибори), стан кампанії вибору та тестового режиму Google Таблиць, картки швидкого доступу до модулів керування, блок «Останні дії в системі» з аудиту Spatie Activitylog, а також детальний регламент та інструкція роботи з імпортом, лімітами та експортом відомостей.
- **Збереження історії вибору для неактивних (архівних) дисциплін**:
  - Якщо дисципліна була активною минулого року і студент її обрав, а цього року вона деактивована (`active = 0`), вибір студента повністю зберігається, відображається у його списку вибору з позначкою `Архівна` та враховується у семестрових квотах і звітах.
  - Для нових студентів неактивні дисципліни приховуються з каталогу та блокуються на рівні бекенду для запобігання помилковому вибору.
- **Динамічні посилання в інтерфейсі**: кнопки та посилання «Google Sheet» на екранах студентів та дисциплін автоматично відкривають активну таблицю (робочу або тестову).
- **Комплексний набір Unit та Feature тестів**: додано 43 автотести (135 assertions) для перевірки головної сторінки з розділенням ролей, версійності, збереження неактивних дисциплін та блокування нових виборів, обмежень семестрових квот, логування аудиту, нормалізації дат, сервісу Google Sheets, збереження налаштувань, експорту Excel та REST API.

### 🐛 Виправлено (Fixed)
- **Нормалізація дат**: у моделі `UserSpecialty` додано мутатори та парсер `parseDateValue()` для автоматичного приведення дат із Google Sheets (`m/d/Y`, `d.m.Y`, `?`) до стандартного формату MySQL `YYYY-MM-DD`. Виправлено помилки `SQLSTATE[22007]`.
- **Захист від помилок `null` при відсутності групи**: виправлено критичні збої `Attempt to read property "semesterLimits" on null` та `semester_count on null` у `SelsubjectListScreen` та `SelSubjectListLayout`.
- **Імпорт студентів без групи**: додано можливість безпечного імпорту здобувачів без вказаної академічної групи (`group_id = null`, `group_name = null`) в `StudentListScreen` та `AuthController`.

### 📚 Документація (Documentation)
- Створено вичерпну технічну документацію архітектури та бази даних у `docs/TECHNICAL_DOCUMENTATION.md`.
- Оновлено `README.md` з описом функціоналу, ролей та інструкцією розгортання.

## [1.3.0] - 2026-03-25

### ✨ Додано (Added)
- **Налаштування вибору дисциплін**: новий екран «Налаштування системи» (`/platform/settings`) для глобального відкриття/закриття кампанії вибору дисциплін студентами.
- **Фільтр стану вибору**: фільтр «Стан вибору дисциплін» (Всі обрані / Частково обрані / Не обрані) та відображення співвідношення вибраних предметів до ліміту групи (наприклад, `15 / 30`).
- **Робочі програми дисциплін**: додано поле `work_program` для перегляду робочих програм дисциплін у форматі PDF.

## [1.2.0] - 2025-11-11

### ✨ Додано (Added)
- **Семестрові ліміти груп**: таблиця `group_semester_limits` та інтерфейс редагування груп для індивідуального налаштування лімітів вибіркових дисциплін на кожен семестр.

## [1.1.0] - 2025-09-04

### ✨ Додано (Added)
- **REST API**: ендпоінт `GET /api/students-subjects` для отримання списку студентів та їхніх вибіркових дисциплін у форматах JSON (з пагінацією) та CSV (потоковий експорт з UTF-8 BOM).
- **Експорт у Excel**: сервіс `StudentsExcelExport` для генерації стилізованих відомостей у форматі `.xlsx`.
- **Журнал аудиту**: інтеграція `spatie/laravel-activitylog` та екран `ActivityLogScreen` для відстеження авторизацій та дій користувачів.
- **Підтримка факультетів та освітніх ступенів**: прив'язка користувачів деканату та студентів до підрозділів (`Department`) і рівнів (`Degree`).

## [1.0.0] - 2025-08-19

### 🚀 Початковий реліз (Initial Release)
- Базова архітектура на базі Laravel та Orchid Platform.
- Авторизація через Google Workspace OAuth 2.0 (SSO) для домену `@dspu.edu.ua`.
- Двостороння інтеграція з Google Sheets API для імпорту студентів (картки ЄДЕБО) та каталогу дисциплін.
- Базовий реєстр вибіркових навчальних дисциплін з можливістю вибору студентами.
